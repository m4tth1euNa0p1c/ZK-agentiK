# Correlated results — October 17, 2026

**The 4,096-vector campaign passes on Windows and GitHub Linux. MATLAB R2026b,
Octave, BigInt and the Rust code agree on the same values.**
The scope is the synthetic `horizon-range-v1` profile, not banking-platform
qualification. Dates come from execution clocks, without a TSA.

An interesting divergence is documented in the self-tests: native `idivide`
divisions tested at u32/u64 maxima agree with the expected quotient in MATLAB
R2026b, but not in Octave 7.3.0. The common oracle avoids this operation for
large integers and reconstructs the quotient exactly bit by bit.
Decimal strings also prevent precision loss beyond `2^53`.
This correction concerns the numerical oracle without replacing Ristretto
arithmetic or a cryptographic primitive.

[128 cases](https://github.com/m4tth1euNa0p1c/ZK-agentic/actions/runs/39052542612) and
[4,096 cases](https://github.com/m4tth1euNa0p1c/ZK-agentic/actions/runs/39052615109),

[short](runs/gha-39052542612-failed/manifest.json) and
[extended](runs/gha-39052615109-failed/manifest.json) bundles retain Rust outputs
and explicitly report missing files; MATLAB had not been launched.

The permissions diagnosis was reproduced with an ephemeral Linux volume:
a 0755 directory owned by UID 1001 denies writes to root without
`CAP_DAC_OVERRIDE`, then accepts UID 1001.
The [probe observations](checks/linux-bind-mount.json) and successful new jobs
support fix `581dbeb`. The runner passes the host UID:GID on Linux, keeps the
network disabled, filesystem read-only, capabilities removed and `/tmp`
ephemeral. It adds no global chmod, secret or capability.
Rootless Docker/user namespaces remain unqualified.

## Demonstration, review and limitations

The [local checks](checks/local-validation.json) cover Rust fmt/Clippy,
workspace tests, TypeScript, Horizon, SDK, schemas and guest.
Eight testbed tests check omissions, duplicates, false success statuses,
wrong denial reasons and substituted corpora, among other things.
Four Rust campaign-binary tests cover real proofs and preflight bypass.
The [quality CI](https://github.com/m4tth1euNa0p1c/ZK-agentic/actions/runs/39053037533)
and [publication CI](https://github.com/m4tth1euNa0p1c/ZK-agentic/actions/runs/39053037539)
succeed on `581dbeb`.

The [authorization demonstration](checks/agentic-demo.json) produces a real
proof and a single synthetic SQLite effect; tampering, replay and reduced
confidentiality are rejected. MCP/stdio scenarios pass separately in
`test:horizon`. The [Proofkit profile](checks/proofkit-profile.json) actually
runs the short campaign. The [HTML report](checks/browser.json) was opened
in headless Chrome with an isolated profile; its script rendered counters,
rows and categories. No complete accessibility audit is claimed.

The [adversarial review](REVIEW.md) led to corrections in provenance,
completeness and native-error checks. The second review of the Linux fix
verified that restrictions remained in place; hashes of the 13 Windows bundle
files, two inputs, two renderers and six view outputs match.
These reviews are internal to the agent team, not an external cryptographic audit.

The [PDF supplement](../../whitepaper/circuit-validation.pdf) contains five
pages of conditional mathematical proof and methodology; it was compiled
without warnings or overflow and its pages inspected. GitHub now rebuilds
this supplement with the main manuscript in the `math` profile.

Raw durations belong to a correction campaign, not a benchmark with warmup
or load isolation. No SLA, GPU advantage, Vega record, post-quantum profile
or machine-checked formal proof of the implementation is established.
Verification uses the same locked library in a separate process; it does not
prove the truth of authorities, metadata confidentiality or remote API atomicity.
H11/H13/H14/H15/H17 remain open.

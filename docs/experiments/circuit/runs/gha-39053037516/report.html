Limites

  • Finite synthetic campaign, not a proof of universal cryptographic soundness.
  • Verifier is a separate process using the same pinned Rust library, not an independent implementation.
  • Public synthetic values reveal this campaign input, never private keys or commitment openings.
  • No external action, no network authorization, no CPU/GPU comparison, no post-quantum security.

Les signatures sont vérifiées hors circuit. Le prover connaît les deux ouvertures. Ce profil n'est pas post-quantique. Les hashes lient les fichiers, sans attester la date ni la vérité des sources. Manifeste des octets et des commandes.

# ZK-agentiK 0.1.0-alpha.1 — Horizon & Proofkit

First prerelease of the laboratory and first standalone distribution of the
Proofkit SDK. The tag freezes the sources, lockfiles and documentation; `main`
remains the development branch.

## Downloads

- `m4tth1euna0p1c-proofkit-sdk-0.1.0-alpha.1.tgz`: ESM SDK, TypeScript
  declarations, documentation and MIT license; Node 24.11+.
- `SHA256SUMS` and `RELEASE.json`: identity of the artifacts, commit and version.
- `whitepaper.pdf`: manuscript kept in the commit, with its historical
  observations; it is not rebuilt by the release workflow.
- GitHub source archives attached to the tag.

```sh
npm install ./m4tth1euna0p1c-proofkit-sdk-0.1.0-alpha.1.tgz
```

The same SDK uses the name `@m4tth1euna0p1c/proofkit-sdk` in GitHub Packages,
on the `alpha` channel. See the
[package guide](https://github.com/m4tth1euNa0p1c/ZK-agentic/blob/v0.1.0-alpha.1/PACKAGES.md)
for registry access and hash verification. The other npm workspaces and the
crates are not published separately.

## What this version contains

The SDK exposes `defineVerifiedTool` with bounded schemas and server-controlled
adapters. Horizon integrates it with real Bulletproofs proofs and a local SQLite
controller, exposed over HTTP and MCP. The sources also contain the
simulator-based DevSecOps demonstration, the separate RISC Zero laboratory,
the proof registry and the correlated mathematical campaigns.

The workflow requires successful CI checks on the tagged commit and tests the
actual installation of the archive outside the monorepo. The run links and the
commit are kept in the release manifest. Earlier scientific results keep their
own scope: they do not become measurements of the new package.

## Experimental status

The API may change. Synthetic data, no financial transaction, no cloud
deployment. Adapters remain trusted. The local SQLite effect does not establish
an exactly-once remote mutation. Horizon is not post-quantum; the historical
simulation discloses the witness. No external cryptographic audit, customer,
regulatory qualification or SLA is claimed. Negative GPU results remain visible.
